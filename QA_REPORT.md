# Проверка Clipnado Studio Lite 0.1.11

Локально в Linux: 179 тестов прошли, один Windows-тест пропущен, семь проверок настоящих моделей вынесены отдельно. Новая проверка настоящей Qwen для подбора сцен и повторного чтения кэша прошла отдельно.

Проверены реальные MP4: все три оформления, движение и границы анимации, субтитры, громкость, пиковый уровень, синхронизация. Семь процедурных сцен проверены по кадрам; отмена удаляет незавершённый рендер. Интерфейс проверен с сохранением/открытием проекта и предпросмотром.

Полная Windows-проверка и запуск готового переносимого пакета ожидаются. Сценарий выпуска заменяет этот файл фактическими результатами только после успешного выполнения всех проверок.

Физический ПК пользователя и его длинные стримы не проверялись. Анимации — вариации семи циклических 2D-сцен; Qwen выбирает параметры, не создаёт произвольный видеоряд. Улучшение удержания зрителей не измерялось.
