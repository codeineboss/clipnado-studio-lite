# Проверка Clipnado Studio Lite 0.1.10

Новая игровая компоновка: камера сверху, игра снизу. Локально проверены настоящий FFmpeg, 720p/1080p, 30/60 FPS, звук и синхронные вспышки, SRT/ASS, отсутствие растяжения и выбор доли камеры. GUI проверен с перетаскиванием областей, сохранением/открытием и отменой; сценарий переносимого GUI локально достиг всех стадий на Linux с тестовыми ответами LLM.

Полный Windows-прогон и проверка встроенного Windows Python ещё не завершены. Фактический итог будет записан сюда из CI перед публикацией. Синтетический тестовый стрим подтверждает геометрию/синхронность, не качество поиска на реальных игровых трансляциях. Скриншоты пользователя использованы как пример компоновки; исходного длинного видео для измерения точности нет.

Предыдущая проверка версии 0.1.9 сохранена в qa/QA_WINDOWS_019.md. Результаты удалённого автокадра не используются как подтверждение новой игровой функции.
