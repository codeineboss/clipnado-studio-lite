# Проверка Windows — Clipnado Studio Lite 0.1.0

Проверка выполнена на GitHub Actions **Windows Server 2022 x64**: https://github.com/Dan1elCarter67/clipnado-studio-lite/actions/runs/43175962514

- 54 теста прошли, включая GUI, экспорт H.264/AAC, субтитры, реальные вызовы FFmpeg, распознавание русской речи и кэш.
- Сам переносимый пакет дополнительно проверен через вложенный Windows Embedded Python: импорты Qt, запуск FFmpeg/ffprobe/Whisper, GUI, ручной интервал и настоящий экспорт MP4.
- whisper.cpp и EXE-запускатель собраны нативно MSVC. Whisper: AVX включён, AVX2/BMI2/FMA/F16C/AVX512/CUDA отключены.
- ZIP проверен на целостность, контрольные суммы находятся в SHA256SUMS.txt.

Не проверены физический Xeon E5-2670, Windows 10 пользователя, GTX 1660/CUDA и человеческое качество отбора нескольких размеченных стримов. Это предварительный выпуск. Автоматические тесты не гарантируют точность отбора.

Сведения об исходной Linux-проверке сохранены ниже как исторический отчёт; её утверждения о ещё не выполненной Windows-проверке относятся к состоянию до этого запуска.

# Отчёт проверки Clipnado Studio Lite 0.1.0

Дата: 12 ноября 2026. Статус: **функциональный MVP / кандидат на Windows-приёмку**. Полная готовность на целевой машине ещё не подтверждена.

## Выполнено в Linux

Среда: Linux x86_64, Python 3.12.14, PySide6 6.8.3, FFmpeg 7.1.5, whisper.cpp 1.8.2, модель Whisper base. GUI проверялся средствами Qt Test в режиме offscreen. Сетевые сценарии Gemini проверялись через подменяемый HTTP-транспорт, без действующего ключа и без оплачиваемых запросов.

- Основной набор: **53 теста прошли**. Отдельный тест реального распознавания русской речи и кэша: **1 тест прошёл**. Всего: **54**. Машиночитаемые результаты приложены в `qa/test-results-main.xml` и `qa/test-results-asr.xml`.
- Предпросмотр: Qt получил валидный видеокадр и изменял позицию воспроизведения. В offscreen-среде нет устройства звукового вывода; аудиосинхронизация проверялась по декодированным данным, а не на слух.
- Для Windows-движка распознавания модель и WAV передаются относительными ASCII-именами внутри рабочей папки: это устраняет зависимость узких C++ argv/fopen от кодовой страницы. Модель временно связывается hard link или копируется при разных дисках.
- GUI: загрузка метаданных, ручной интервал, редактирование границ/текста, отметки, сортировка, выбор лучших кандидатов перед сортировкой по времени, экспорт SRT/MP4, изменение границ и повторный экспорт, сохранение/открытие проекта.
- Во время экспорта GUI обрабатывал периодические таймеры. Серия из 40 фоновых задач завершилась с освобождением потоков. Найденный при регрессии сбой времени жизни Qt-потока устранён: QObject сигналов остаётся в UI-потоке, вычисления выполняются в Python-thread, завершение синхронизируется перед удалением объекта. Повторное открытие того же исходника не перезапускает медиаплеер.
- Метаданные синтетических файлов длительностью 15 минут, 30 минут и 5 часов прочитаны корректно. **Это тест импорта, а не полного распознавания многочасового стрима.**
- Проверены повреждённый MP4, отсутствие аудио, 29.97 FPS, кириллица, пробелы и апострофы в путях, неверные таймкоды/рейтинги, повреждённый проект, отмена запущенного процесса, недостаток места (инъекция ошибки).
- Реально закодированы и полностью декодированы 9:16 / 16:9 / 1:1. Проверены 720p и стартовые 1080×1920 / 30 FPS, H.264/AAC, сдвиг верхней зоны, отсутствие звука, повторный экспорт. Анаморфный источник с SAR=2 также проверен: пропорции сохраняются.
- Пиксельные проверки подтверждают чёрную нижнюю зону, в том числе при встроенных субтитрах во всех трёх форматах. Проверено сохранение пропорций красного тестового кадра и наличие отрисованных кириллических символов.
- Синхронный тестовый световой импульс и звук после обрезки оставались около одной временной отметки с допуском 100 мс. Стартовые метки аудио/видео дополнительно проверяются самим экспортёром.
- SRT проверен на корректное смещение к началу клипа и отсечение по его длине. Экспорт без текста при включённых субтитрах останавливается с понятной ошибкой.
- Проект сохраняется атомарно, невалидная запись не повреждает предыдущий файл. Повторный экспорт использует сохранённые сегменты; API при экспорте не вызывается. Перепривязка сверяет полный SHA-256 исходника.
- Gemini: отсутствие ключа, отказ от согласия, отказ от подтверждения Free Tier, неверный ключ/доступ (400/401/403/404), квота (429), отключённая сеть, некорректные интервалы в ответе. При 429 запрос не повторяется. Ошибки HTTP не включают тело ответа или ключ; в запросе только текст/таймкоды, без имени файла, идентификатора исходника, видео или аудио. Локальная альтернатива выбирается пользователем.

## Распознавание и качество поиска

1. На публичном **человеческом** образце FLEURS `ru_ru/test`, файл `10000611681338527501.wav`, реальный whisper.cpp с AVX, без AVX2/BMI2/FMA/F16C, распознал русскую фразу про династии Китая. В одном измерении без пунктуации: 21 слово эталона, 4 словесные правки, WER ≈19%. Это **одно наблюдение**, а не оценка точности на стримах. Эталон, звук, исходный результат и атрибуция находятся в `qa/` / `THIRD_PARTY.md`.
2. Английский контрольный человеческий образец JFK из репозитория whisper.cpp распознан по смыслу корректно. В приложении установлен русский язык; этот запуск проверял сам движок отдельно.
3. Синтетический русский голос eSpeak был распознан плохо (только короткие фрагменты). Для очень короткой расшифровки добавлено предупреждение. Подмена этого результата вручную исправленным текстом не выдаётся за распознавание.
4. На искусственно размеченной расшифровке выделен событийный диапазон, нейтральный текст не добивался до 15 кандидатов. Проверены длительности и отсутствие сильных пересечений. Демонстрационный проект использует заранее заданный автором текст и синтетическое видео; это отмечено в самом проекте.
5. **Человеческая оценка попаданий и ложных срабатываний на нескольких реальных размеченных длинных видео не проведена: таких записей в исходных материалах нет.** Качество контекстного отбора нельзя признать прошедшим приёмку по формальным тестам. Локальный метод — ограниченная эвристика, не полноценная смысловая модель.

## Windows-пакет и оставшиеся проверки

Подготовлен переносимый каталог с Windows Embedded Python 3.13.9, Windows wheels PySide6 6.8.3, FFmpeg 8.1.2 Gyan, многоязычной моделью base, собственным EXE-запускателем и кросс-собранным Windows whisper-cli.exe. Whisper собран LLVM-MinGW 20250613 из commit `4979e04f5dcaccb36057e059bbaed8a2f5288315`; проверен формат PE x64 и импорты системных библиотек. AVX2, BMI2, FMA, F16C, AVX512 и CUDA отключены. Контрольные суммы модели, FFmpeg и файлов пакета сохранены.

**Windows EXE не запускался на настоящей Windows.** Попытка проверить его через локально распакованный Wine завершилась ошибкой самого Wine (`could not load kernel32.dll`, c0000135); это не проверка работоспособности приложения. Поэтому в MANIFEST выставлено `windows_execution_verified: false`.

Не проверены:

- запуск полного переносимого пакета и GUI на Windows 10 / Xeon E5-2670 без AVX2;
- реальная работа Windows Credential Manager и предпросмотра на драйверах пользователя;
- GTX 1660 / CUDA (комплект работает через CPU, сборочный сценарий CUDA приложен отдельно);
- реальный Gemini Free для пользовательского ключа, региональные ограничения и действующие квоты;
- скорость и качество отбора полного 15–30-минутного стрима, полного 5-часового распознавания и воспроизведения результата в CapCut;
- человеческая оценка нескольких размеченных стримов.

Окончательная приёмка по исходному ТЗ требует этих проверок. Наличие переносимого архива и успешных Linux-тестов не означает, что они уже выполнены.

## Повторение проверок

```powershell
python -m pip install -e ".[dev]"
python -m pytest -q --ignore=tests/test_asr.py
$env:CLIPNADO_TEST_WHISPER = (Resolve-Path tools/whisper-cli.exe).Path
$env:CLIPNADO_TEST_MODEL = (Resolve-Path models/ggml-base.bin).Path
python -m pytest tests/test_asr.py -q
```

Для тестов без экрана: `QT_QPA_PLATFORM=offscreen`. В Windows используйте реальные FFmpeg/ffprobe из PATH. В Linux пути к движку/модели задаются аналогичными переменными окружения. `diagnostics.cmd` проверяет переносимый Windows-пакет без передачи данных в сеть.
