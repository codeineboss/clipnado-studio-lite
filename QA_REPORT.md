# Проверка Clipnado Studio Lite 0.1.4

Локальная версия находится на этапе сборки и Windows-проверки. Итоговый отчёт с количеством тестов и ссылкой на запуск формируется автоматически в файлах выпуска только после полного прохождения нативных тестов и проверки переносимого пакета.

В Linux выполнен реальный запуск Qwen3-4B-Instruct-2507 Q3_K_M через llama.cpp без API. Модель выбрала интервал 00:20–01:20 с вопросом ученика и ответом учителя в составленном диалоге. Материалы: `qa/qwen-dialogue-fixture.json`, `qa/qwen-linux-result.json`, [подробности](qa/LOCAL_MODEL_014.md).

Физические Xeon E5-2670 и GTX 1660 недоступны в среде проверки. Достоверного измерения скорости на пользовательском видео и человеческой оценки точности на размеченных стримах нет. Один авторский пример не подтверждает универсальное качество отбора.
