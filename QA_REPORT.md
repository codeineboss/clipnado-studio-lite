# Проверка Clipnado Studio Lite 0.1.12

Локально в Linux: 186 тестов прошли, один Windows-тест пропущен, семь проверок настоящих моделей вынесены отдельно. Для всех стилей автоматического поиска установлен общий диапазон 30–90 секунд. Текущий выпуск добавляет профили мемных нарезок и удаляет встроенные анимации по запросу пользователя.

Проверены: профили поиска/экспорта, сохранение и старые проекты, сохранность индивидуальных вариантов клипов, импорт прежних полей анимаций и кэша Qwen, чёрная нижняя зона в готовом MP4, обработка цвета/звука, субтитры, прежние игровые и другие оформления.

Настоящая Qwen проверяется отдельно на авторском коротком диалоге. Полная Windows-проверка и запуск переносимого пакета ожидаются. Сценарий выпуска заменяет этот файл фактическими результатами только после всех проверок.

Физический ПК пользователя и его длинные стримы не проверялись. Профили не прогнозируют охват публикаций и не гарантируют десять интересных эпизодов для любой записи. Проблема детализации камеры на конкретном видео пользователя пока не сравнивалась с его исходником.
