# Проверка Clipnado Studio Lite 0.1.9

Локальные проверки: регрессия, настоящий FFmpeg, YuNet и Light-ASD; эталонное сравнение MFCC и ONNX. Эмуляция Linux SandyBridge успешно выполнила обе модели без AVX2/FMA/F16C/BMI2.

Полный Windows-прогон и проверка готового переносимого пакета выполняются перед публикацией. Этот файл будет заменён фактическим отчётом выпуска. Проверка определения говорящего на размеченных реальных разговорах и физическом ПК пользователя пока не проводилась. Синтетический NASA-портрет проверяет выполнение модели и геометрию, не точность речи.

Предыдущий подтверждённый отчёт: [0.1.8](qa/QA_REPORT_0.1.8.md).
