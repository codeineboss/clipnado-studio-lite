# Clipnado Studio Lite 0.1.12

Локальная Windows-программа: длинное видео → эпизоды → вертикальные клипы для TikTok и заготовки для CapCut. Whisper base распознаёт речь, Qwen3-4B выбирает моменты по содержанию. API, ключи и онлайн-анализ не нужны. Код приложения написан самостоятельно.

## Профили мемных нарезок

Слева выберите **«Стиль поиска»**: мемы, один законченный момент, событие и реакция или законченный рассказ. **Для всех стилей общий диапазон автоматического поиска — 30–90 секунд**, по вашему запросу. Стили меняют редакторские указания Qwen: сохранить необходимую завязку, событие, неожиданный ответ и реакцию, убрать пустую подводку. Верхняя граница — 90 секунд; минимальную можно повысить в пределах этого диапазона. Смена стиля не удаляет клипы и не запускает модель; для нового отбора нажмите «Найти эпизоды».

Старые проекты открываются с найденными клипами и расшифровкой. В интерфейсе поиска их лимиты приводятся к 30–90 секундам; существующие клипы автоматически не обрезаются и не удаляются. Кэш расшифровки используется повторно. Смена длительности или редакторского стиля создаёт отдельный кэш отбора.

В «Экспорт» выберите **«Готовое оформление» → «Применить профиль»**:

| Профиль | Компоновка |
|---|---|
| Игровые мемы | Камера сверху 35%, игра снизу 65%; выделите области один раз |
| Разговор / IRL | Видео целиком по центру, затемнение размытого фона 30% |
| Рассказ | Видео сверху, нижняя чёрная зона для собственного монтажа |

Общие параметры профилей: 9:16, 1080p, CRF 18, FPS по источнику из доступных 24/25/30/50/60, исходные цвета, выравнивание всего звука и читаемые встроенные субтитры, если расшифровка уже есть. Если применили профиль до получения текста, субтитры останутся выключенными — включите их после поиска или примените профиль повторно.

Области камеры/игры и индивидуальный выбор оформления в строках сохраняются. Чтобы всем отмеченным клипам назначить общий вариант, нажмите «Применить общее ко всем». Ручное изменение параметров переводит профиль оформления в «Свои настройки». Настройки сохраняются в проекте. Новый поиск для смены оформления не нужен.

Это монтажные заготовки, а не прогноз популярности. Их длительности и пропорции — рабочие варианты для проверки на своей аудитории. У платформ нет подтверждённого преимущества именно выбранного фона. Для отбора важны понятный контекст, событие и реакция; рост просмотров не обещается. Qwen не видит изображение и не может подтвердить игровое событие без соответствующей речи.

Основания для рекомендаций: [сигналы рекомендаций TikTok](https://support.tiktok.com/en/using-tiktok/exploring-videos/how-tiktok-recommends-content), [ранжирование Shorts YouTube](https://support.google.com/youtube/answer/11914225?co=YOUTUBE._YTVideoType%3Dshorts&hl=en), [технические рекомендации TikTok для рекламы](https://ads.tiktok.com/resources/help/article/creative-best-practices). Последние не являются исследованием органического охвата мемных нарезок.

## Изображение, звук и свободная нижняя зона

Во вкладке «Экспорт» есть блок **«Изображение и звук»**. Настройки общие для отмеченных клипов и сохраняются в проекте. Повторный поиск моментов не требуется.

- **Цвет:** исходный, мягкая коррекция или немного светлее. Растяжения нет; осветление лучше включать по предпросмотру. Исходник низкого качества не станет детальнее от коррекции.
- **Звук:** по желанию выравнивается весь микс отрывка с двухпроходным измерением (цель −16 LUFS, пик −1,5 dBTP); очень тихие записи усиливаются не более чем на 12 дБ. Тишина сохраняется. Игра и речь отдельно не выделяются.
- **Субтитры:** включите SRT/встраивание и «Крупнее, не более двух коротких строк». Длинная реплика делится на карточки без потери слов. Внутри реплики время распределяется приблизительно, это не пословная синхронизация. Можно оставить прежний стиль.
- **Размытый фон:** затемнение 0–60% влияет только на фон, исходное видео по центру остаётся резким. Для нового проекта — 25%; старые проекты сохраняют прежнюю яркость.

Встроенные анимации, их настройки и планировщик Qwen удалены. В формате «Видео сверху · тёмная зона» нижняя часть MP4 остаётся чёрной, чтобы вы добавляли собственные анимации в редакторе. Старые проекты с настройками анимаций открываются; прежние поля игнорируются. Папки старого кэша не удаляются автоматически, их можно убрать при закрытой программе.

«Предпросмотр кадра» показывает выбранную композицию, цвет и встроенные субтитры. Звук проверяйте в готовом MP4.

## Игровая нарезка: стример сверху, игра снизу

Новый вариант экспорта заменяет «TikTok · на весь кадр 9:16» и слежение за говорящим. Итог — один вертикальный MP4: сверху область веб-камеры, снизу выбранная область игры. Обе части берутся из одного отрывка, исходный звук сохраняется. Камера и игра заполняют свои зоны без растяжения и дополнительного размытия.

1. Загрузите длинный стрим → «Найти эпизоды» → отметьте нужные клипы.
2. Во вкладке «Экспорт» для нужных строк выберите **«Игровая нарезка · стример сверху, игра снизу»**. Для остальных клипов можно выбрать верхнюю тёмную зону или размытый фон.
3. Нажмите **«Камера и игра…»**. На исходном кадре выделите бирюзовой рамкой веб-камеру, жёлтой — игру. Рамку можно рисовать, перемещать и менять за углы; точные размеры доступны в процентах. Есть заготовки камеры справа/слева сверху. Первоначально узкие чёрные полосы в области игры предлагается исключить.
4. Если в начале заставка, выберите другое время и нажмите «Показать кадр». Задайте долю камеры сверху: **25–60%, по умолчанию 40%**. Справа сразу видна компоновка 9:16. Нажмите «Применить к видео».
5. Разметка сохраняется в проекте и применяется ко всем игровым клипам этого видео. Повторно искать эпизоды или размечать каждый клип не нужно. «Предпросмотр кадра» показывает точный вариант выбранной строки через FFmpeg, включая встроенные субтитры.
6. Для высокого качества выберите **1080p, CRF 18** и FPS исходника. Нажмите «Экспортировать отмеченные». Экспорт кодирует исходные кадры один раз; уменьшенный предпросмотр не используется как источник MP4. Детализация маленькой веб-камеры ограничена исходной записью.

Выбирайте область игры так, чтобы в неё не попадали веб-камера, рамки и чёрные полосы. Если её пропорции отличаются от нижней зоны, лишние края обрезаются по центру — результат виден в предпросмотре. Готовое игровое видео всегда 720×1280 или 1080×1920, даже если общий холст других клипов квадратный или горизонтальный.

Два других оформления сохранены: «Видео сверху · тёмная зона» оставляет свободное место для вашего монтажа, «Видео по центру · размытый фон» показывает исходный кадр целиком. Общее оформление применяется к клипам без собственного выбора; «Применить общее ко всем» сбрасывает индивидуальные варианты отмеченных клипов. Разрешение, FPS, качество и субтитры общие. Для игровой компоновки позиция субтитров задаётся от верха всего вертикального кадра.

## Проекты и поиск

Старые проекты открываются с сохранёнными расшифровками, границами и отметками. Старый вариант полного кадра TikTok заменяется игровой компоновкой; перед его первым экспортом нужно задать области. Для каждого нового видео разметка независимая.

Поиск по содержанию, подбор соседних границ с просмотром/отменой и обычный поиск сохранены. Распознанный текст и совместимый кэш используются повторно. Для нового смыслового запроса Qwen снова проходит по тексту; подбор границ смотрит соседний контекст. Защита контекста 8192 токена сохранена.

Qwen выбирает моменты по **расшифровке речи**, а не по кадрам игры: реакции и разговоры анализируются, чисто визуальное игровое событие может быть пропущено. Цель 10 клипов с порогом 60 — настройка отбора; программа сообщает о недоборе и не повышает оценки ради количества. Оценка не является прогнозом просмотров.

Экспорт создаёт H.264/AAC MP4 и проверяет его полным декодированием. Субтитры можно отключить, сохранить SRT или встроить. Файлы не перезаписываются; отмена удаляет незавершённый текущий клип. Сохраните проект, чтобы вернуться к расшифровке, отбору и разметке. Видео и GGUF не включаются в проект.

## Требования и сборка

Windows 10/11 x64, CPU с AVX, целевой ПК — Xeon E5-2670, 32 ГБ RAM, GTX 1660 6 ГБ. Нативные движки собраны без AVX2/FMA/F16C/BMI2/AVX512. Vulkan использует драйвер видеокарты, CUDA Toolkit не нужен. При ошибке GPU программа повторяет анализ на CPU; CPU-поиск на старом Xeon может быть долгим. Физическая проверка указанного ПК не проводилась.

Для программы, моделей и кэша оставьте около 8 ГБ, отдельно — место для видео и экспортов. При переносе между дисками GGUF может копироваться в кэш; на одном диске используется hard link.

Для запуска исходников: Python 3.10–3.13 x64, FFmpeg/libx264/libass, нативные Whisper/llama CLI в `tools`, модели в `models` или настройках.

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -e ".[dev]"
.venv\Scripts\python run.py
.venv\Scripts\python -m pytest -q
```

Полная проверка и доставка: `.github/workflows/deliver-windows.yml`. Готовый переносимый пакет проверяется до долгого набора тестов моделей. Реальные тесты включаются через `CLIPNADO_TEST_WHISPER`, `CLIPNADO_TEST_MODEL`, `CLIPNADO_TEST_LLAMA`, `CLIPNADO_TEST_QWEN`; в выпуске пропуски запрещены. В Linux без экрана: `QT_QPA_PLATFORM=offscreen`.

Данные Windows: `%LOCALAPPDATA%/ClipnadoStudioLite`; Linux: `$XDG_DATA_HOME/ClipnadoStudioLite` или `~/.local/share/ClipnadoStudioLite`. Переменная `CLIPNADO_DATA_DIR` переопределяет путь. Старые записи Credential Manager не используются и автоматически не удаляются.
