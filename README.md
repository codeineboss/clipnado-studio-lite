# Clipnado Studio Lite 0.1.8

Локальная Windows-программа для отбора эпизодов и экспорта заготовок для CapCut. **Whisper base распознаёт речь, Qwen3-4B-Instruct-2507 выбирает эпизоды по смыслу.** API, регистрация, ключи и онлайн-анализ удалены. После скачивания файлов сеть не нужна. Код приложения написан самостоятельно, код Supoclip не включён.

Добавлено в 0.1.8: **индивидуальное оформление каждого выбранного клипа на стадии экспорта**.

1. Загрузите длинное видео → найдите моменты → отметьте нужные эпизоды.
2. Откройте «Экспорт». В таблице отображаются все отмеченные клипы, включая скрытые за «Показать ещё» в основном списке.
3. В каждой строке выберите один из трёх вариантов:
   - «Видео сверху · тёмная зона» — нижняя часть остаётся для анимаций.
   - «Видео по центру · размытый фон» — исходный кадр целиком по центру, фон из того же видео движется синхронно.
   - **«TikTok · на весь кадр 9:16»** — один резкий вертикальный кадр без полей и заднего фона. Видео сохраняет пропорции, лишние края обрезаются по центру. Горизонтальный исходник теряет боковые части. Этот режим всегда создаёт 720×1280 или 1080×1920, даже если остальные клипы очереди квадратные или горизонтальные.
4. Выберите строку → «Предпросмотр кадра». Он показывает один кадр выбранного клипа с заданным оформлением, без субтитров. Предпросмотр уменьшен для экрана; это проверка кадрирования, а не качества конечного MP4.
5. Задайте разрешение, FPS, качество H.264, субтитры и папку результата. Для высокого качества доступны 1080p и «Высокое · CRF 18»; детализация зависит от исходного видео. Нажмите «Экспортировать отмеченные» — все выбранные варианты создаются одной очередью с исходным звуком. Повторный поиск моментов для смены оформления не требуется.

«Общее оформление» применяется к клипам без индивидуального выбора. Изменение общего значения сохраняет уже сделанный индивидуальный выбор; «Применить общее ко всем» назначает текущее общее оформление всем отмеченным клипам. Выбор сохраняется в проекте и следует за клипом при сортировке и снятии/возврате отметки.

Разрешение, FPS, качество и режим субтитров общие. В режиме TikTok и на размытом фоне позиция встроенных субтитров задаётся от верха всего холста; при верхнем размещении текст должен попадать в зону видео. Настройки каждого выбранного оформления проверяются до начала очереди. Кнопка экспорта доступна внизу вкладки при прокрутке настроек.

Поиск по содержанию, подбор соседних границ с просмотром/отменой и обычный поиск 0.1.7 сохранены. Для поиска по смыслу введите запрос и нажмите «Найти по содержанию»: результаты открываются отдельно и добавляются в эпизоды по выбору. Для сравнения соседних интервалов выберите эпизод → «Подобрать границы» → просмотрите и примените вариант; до применения границы сохраняются.

Новые запросы используют отдельный кэш; обычный поиск и его завершённые результаты 0.1.5–0.1.7 совместимы. Измерение полного запроса настоящим токенизатором, запас для ответа и автоматическое разбиение большого контекста сохранены. Контекст остаётся 8192 токена. Распознанный текст используется повторно; поиск по всей расшифровке требует нового прохода Qwen для каждого нового запроса. Подбор границ проверяет только контекст рядом с выбранным клипом.

**Обновление:** распакуйте новый ZIP в отдельную папку. Прежний GGUF можно скопировать в `models` или указать его старый путь — скачивать модель заново не нужно. Старые проекты открываются с прежним общим оформлением для всех клипов; индивидуальные варианты можно выбрать во вкладке «Экспорт».

## Скачать и открыть

1. Скачайте и полностью распакуйте [программу Windows x64](https://github.com/Dan1elCarter67/clipnado-studio-lite/releases/download/preview-0.1.8/ClipnadoStudioLite-Windows-x64.zip).
2. Скачайте [модель Qwen GGUF — 2,08 ГБ](https://github.com/Dan1elCarter67/clipnado-studio-lite/releases/download/preview-0.1.8/Qwen_Qwen3-4B-Instruct-2507-Q3_K_M.gguf). Положите этот файл без переименования в папку `models` распакованной программы. Также можно выбрать его кнопкой «Указать модель Qwen (.gguf)».
3. Запустите `ClipnadoStudioLite.exe` или `start.cmd`. Python, FFmpeg, Whisper base и CPU/Vulkan-движки включены. При проблеме запуска откройте `diagnostics.cmd`; журнал — `%LOCALAPPDATA%/ClipnadoStudioLite/startup-error.log`.

[Все файлы выпуска](https://github.com/Dan1elCarter67/clipnado-studio-lite/releases/tag/preview-0.1.8). Для закрытого репозитория войдите в GitHub под аккаунтом с доступом. **145 тестов Windows прошли без пропусков**: GUI, реальный FFmpeg, три оформления, сохранение проектов, настоящие Whisper/Qwen и кэш. [Набор тестов](https://github.com/Dan1elCarter67/clipnado-studio-lite/actions/runs/43720145763). Готовый пакет отдельно прошёл [повторную проверку](https://github.com/Dan1elCarter67/clipnado-studio-lite/actions/runs/43727219091): настоящее выполнение Qwen, видео, экспорт трёх оформлений одной очередью и предпросмотр. Между проверками изменены только сценарии проверки/доставки пакета; исходники приложения, тестов, зависимостей и настройки нативной сборки совпадают. [Подробный отчёт](QA_REPORT.md).

Нужны Windows 10/11 x64, CPU с AVX и 32 ГБ RAM для целевого ПК; комплектные движки собраны без AVX2/BMI2/FMA/F16C/AVX512 для Xeon E5-2670. При наличии Vulkan-драйвера программа автоматически использует GPU, затем освобождает память перед следующим этапом. При ошибке GPU повторяет этап через CPU. В настройках можно принудительно выбрать CPU. На GTX 1660 с 6 ГБ VRAM Qwen квантизации Q3_K_M рассчитана на размещение на видеокарте; физическая проверка этого оборудования ещё не проведена. CUDA Toolkit не требуется.

Для программы, модели и первоначального кэша оставьте около 8 ГБ свободного места, отдельно — место для исходников и экспортов. Если модель и кэш на разных дисках, GGUF один раз копируется в кэш; на одном диске используется hard link. Первый поиск включает проверку модели и может быть дольше последующих.

## Работа

1. «Выбрать видео» → дождаться чтения метаданных и контрольной суммы.
2. «Найти эпизоды»: по умолчанию длина 60–90 с, цель 10 клипов, порог 60. Анализ идёт в фоне. Распознанные блоки и обработанные окна Qwen сохраняются; отменённый поиск можно продолжить. Отчёт показывает полноту проверки, выбранные движки и время этапов.
3. Просмотрите клипы: выберите строку → «Фрагмент». Без выбранной строки кнопка «Видео» проигрывает исходник. Границы редактируются в таблице в формате `ЧЧ:ММ:СС.мс`; «＋ Вручную» добавляет интервал от текущей позиции. «Показать ещё» раскрывает резерв кандидатов.
4. Исправьте расшифровку или импортируйте UTF-8 SRT во вкладке «Расшифровка». При новом анализе готовый текст используется повторно. Смена папки кэша позволяет выполнить перерасчёт.
5. Во вкладке «Экспорт» выберите оформление, формат, разрешение, FPS и субтитры; для верхнего размещения задайте зону видео. «Экспортировать отмеченные» создаёт H.264/AAC MP4 и проверяет декодирование результата. Повторный экспорт не запускает модели. Готовые файлы не перезаписываются, отмена удаляет только незавершённый текущий клип.
6. Сохраните проект: видео и модели в него не включаются. При переносе видео используйте перепривязку.

Qwen анализирует **расшифровку, а не изображение**. Без речевого контекста визуальные шутки могут быть пропущены. Оценка — внутренний балл модели, не прогноз просмотров. Подходящих десяти непересекающихся эпизодов может не быть; программа сообщает недобор, не повышает баллы ради количества. Точность на нескольких размеченных реальных стримах и скорость на вашем ПК пока не измерены. CPU-анализ на старом Xeon может занимать долгое время. Демопроект содержит искусственное видео и авторский текст, он проверяет интерфейс и экспорт.

## Сборка и проверки

Python 3.10–3.13 x64; FFmpeg с libx264/libass в PATH. Для запуска из исходников положите нативные CLI в `tools`, модели в `models` или укажите пути в настройках.

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -e ".[dev]"
.venv\Scripts\python run.py
.venv\Scripts\python -m pytest -q
```

Полная Windows-сборка и проверка: `.github/workflows/deliver-windows.yml`. Сценарии `scripts/build_windows.ps1` и `scripts/build_local_models.ps1` собирают закреплённые версии Whisper, llama.cpp и Vulkan-движков. Реальные тесты моделей включаются переменными `CLIPNADO_TEST_WHISPER`, `CLIPNADO_TEST_MODEL`, `CLIPNADO_TEST_LLAMA`, `CLIPNADO_TEST_QWEN`; в выпуске пропуски запрещены. В Linux для Qt без экрана используйте `QT_QPA_PLATFORM=offscreen`.

Данные: `%LOCALAPPDATA%/ClipnadoStudioLite` в Windows, `$XDG_DATA_HOME/ClipnadoStudioLite` или `~/.local/share/ClipnadoStudioLite` в Linux; путь переопределяется `CLIPNADO_DATA_DIR`. Новые настройки не содержат API-ключей; старые записи Credential Manager не используются и автоматически не удаляются.
