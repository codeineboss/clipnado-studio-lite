# Clipnado Studio Lite 0.1.6

Локальная Windows-программа для отбора эпизодов и экспорта заготовок для CapCut. **Whisper base распознаёт речь, Qwen3-4B-Instruct-2507 выбирает эпизоды по смыслу.** API, регистрация, ключи и онлайн-анализ удалены. После скачивания файлов сеть не нужна. Код приложения написан самостоятельно, код Supoclip не включён.

Исправление 0.1.6: перед анализом проверяется фактическое число токенов **полного запроса**, включая инструкции, разметку чата и список клипов. Нативный движок считает токены в режиме без генерации. Для ответа и повторной проверки оставлен отдельный запас. Слишком большой участок автоматически делится с перекрытием, без обрезки текста. Контекст остаётся 8192 токена; расход видеопамяти не увеличивается. Ошибка переполнения не вызывает повтор того же запроса на CPU.

Смысловой отбор по допустимым ID сохранён. Обработанные части кэшируются независимо; при повторном поиске завершённые части используются снова. Совместимые результаты 0.1.5 переносятся автоматически. Одиночная реплика, которую невозможно вместить даже после сокращения таблицы клипов, явно помечается непроверенной и не останавливает остальные участки.

**Обновление с 0.1.4–0.1.5:** распакуйте новый ZIP в отдельную папку и скопируйте прежний GGUF в `models` либо укажите старый файл кнопкой выбора модели. Повторная загрузка 2 ГБ не требуется. Откройте прежний проект или видео и повторите поиск: готовая расшифровка используется снова, совместимые завершённые результаты 0.1.5 сохраняются.

## Скачать и открыть

1. Скачайте и полностью распакуйте [программу Windows x64](https://github.com/Dan1elCarter67/clipnado-studio-lite/releases/download/preview-0.1.6/ClipnadoStudioLite-Windows-x64.zip).
2. Скачайте [модель Qwen GGUF — 2,08 ГБ](https://github.com/Dan1elCarter67/clipnado-studio-lite/releases/download/preview-0.1.6/Qwen_Qwen3-4B-Instruct-2507-Q3_K_M.gguf). Положите этот файл без переименования в папку `models` распакованной программы. Также можно выбрать его кнопкой «Указать модель Qwen (.gguf)».
3. Запустите `ClipnadoStudioLite.exe` или `start.cmd`. Python, FFmpeg, Whisper base и CPU/Vulkan-движки включены. При проблеме запуска откройте `diagnostics.cmd`; журнал — `%LOCALAPPDATA%/ClipnadoStudioLite/startup-error.log`.

[Все файлы выпуска](https://github.com/Dan1elCarter67/clipnado-studio-lite/releases/tag/preview-0.1.6). Для закрытого репозитория войдите в GitHub под аккаунтом с доступом. Проверка текущей версии — [QA_REPORT.md](QA_REPORT.md).

Нужны Windows 10/11 x64, CPU с AVX и 32 ГБ RAM для целевого ПК; комплектные движки собраны без AVX2/BMI2/FMA/F16C/AVX512 для Xeon E5-2670. При наличии Vulkan-драйвера программа автоматически использует GPU, затем освобождает память перед следующим этапом. При ошибке GPU повторяет этап через CPU. В настройках можно принудительно выбрать CPU. На GTX 1660 с 6 ГБ VRAM Qwen квантизации Q3_K_M рассчитана на размещение на видеокарте; физическая проверка этого оборудования ещё не проведена. CUDA Toolkit не требуется.

Для программы, модели и первоначального кэша оставьте около 8 ГБ свободного места, отдельно — место для исходников и экспортов. Если модель и кэш на разных дисках, GGUF один раз копируется в кэш; на одном диске используется hard link. Первый поиск включает проверку модели и может быть дольше последующих.

## Работа

1. «Выбрать видео» → дождаться чтения метаданных и контрольной суммы.
2. «Найти эпизоды»: по умолчанию длина 60–90 с, цель 10 клипов, порог 60. Анализ идёт в фоне. Распознанные блоки и обработанные окна Qwen сохраняются; отменённый поиск можно продолжить. Отчёт показывает полноту проверки, выбранные движки и время этапов.
3. Просмотрите клипы: выберите строку → «Фрагмент». Без выбранной строки кнопка «Видео» проигрывает исходник. Границы редактируются в таблице в формате `ЧЧ:ММ:СС.мс`; «＋ Вручную» добавляет интервал от текущей позиции. «Показать ещё» раскрывает резерв кандидатов.
4. Исправьте расшифровку или импортируйте UTF-8 SRT во вкладке «Расшифровка». При новом анализе готовый текст используется повторно. Смена папки кэша позволяет выполнить перерасчёт.
5. Во вкладке «Экспорт» задайте формат, разрешение, FPS, зону видео и субтитры. «Экспортировать отмеченные» создаёт H.264/AAC MP4 и проверяет декодирование результата. Повторный экспорт не запускает модели. Готовые файлы не перезаписываются, отмена удаляет только незавершённый текущий клип.
6. Сохраните проект: видео и модели в него не включаются. При переносе видео используйте перепривязку.

Qwen анализирует **расшифровку, а не изображение**. Без речевого контекста визуальные шутки могут быть пропущены. Оценка — внутренний балл модели, не прогноз просмотров. Подходящих десяти непересекающихся эпизодов может не быть; программа сообщает недобор, не повышает баллы ради количества. Точность на нескольких размеченных реальных стримах и скорость на вашем ПК пока не измерены. CPU-анализ на старом Xeon может занимать долгое время. Демопроект содержит искусственное видео и авторский текст, он проверяет интерфейс и экспорт.

## Сборка и проверки

Python 3.10–3.13 x64; FFmpeg с libx264/libass в PATH. Для запуска из исходников положите нативные CLI в `tools`, модели в `models` или укажите пути в настройках.

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -e ".[dev]"
.venv\Scripts\python run.py
.venv\Scripts\python -m pytest -q
```

Полная Windows-сборка и проверка: `.github/workflows/deliver-windows.yml`. Сценарии `scripts/build_windows.ps1` и `scripts/build_local_models.ps1` собирают закреплённые версии Whisper, llama.cpp и Vulkan-движков. Реальные тесты моделей включаются переменными `CLIPNADO_TEST_WHISPER`, `CLIPNADO_TEST_MODEL`, `CLIPNADO_TEST_LLAMA`, `CLIPNADO_TEST_QWEN`; в выпуске пропуски запрещены. В Linux для Qt без экрана используйте `QT_QPA_PLATFORM=offscreen`.

Данные: `%LOCALAPPDATA%/ClipnadoStudioLite` в Windows, `$XDG_DATA_HOME/ClipnadoStudioLite` или `~/.local/share/ClipnadoStudioLite` в Linux; путь переопределяется `CLIPNADO_DATA_DIR`. Новые настройки не содержат API-ключей; старые записи Credential Manager не используются и автоматически не удаляются.
