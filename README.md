## Переносимый Windows-пакет

1. Полностью распакуйте `ClipnadoStudioLite-Windows-x64.zip` в обычную локальную папку. Не запускайте программу прямо из ZIP.
2. Запустите `ClipnadoStudioLite.exe` или `start.cmd`. Установка Python, FFmpeg и загрузка модели для комплектного CPU-режима не нужны: всё включено. Нужны Windows 10/11 x64 и примерно 2 ГБ места после распаковки.
3. Если окно не появляется, запустите `diagnostics.cmd`. Он проверит импорты Qt, запуск инструментов и наличие модели без обращения к сети. Ошибка запуска GUI записывается в `%LOCALAPPDATA%/ClipnadoStudioLite/startup-error.log`.
4. Для знакомства откройте проект в папке `demo`. Это демонстрация интерфейса и экспорта, а не доказательство точности поиска.

Комплектный `whisper-cli.exe` собран из whisper.cpp v1.8.2: **AVX включён, AVX2, BMI2, FMA, F16C, AVX512 и CUDA отключены**. Xeon E5-2670 поддерживает AVX. Исполнение этой Windows-сборки на физическом Xeon ещё не проверено. FFmpeg имеет динамическое определение возможностей CPU. Модель `base` многоязычная; язык распознавания — русский. Большие модели могут повысить качество ценой времени и памяти: выберите совместимую GGML-модель в настройках.

## Основной сценарий

1. «Выбрать видео». Дождитесь чтения метаданных и SHA-256 исходника. Для большого файла это занимает некоторое время; задача выполняется в фоне и отменяется.
2. Для визуальных и звуковых событий выберите **Gemini Free · видео и звук**; для серверного распознавания и смыслового отбора по речи — **Groq Free · звук и текст**. Введите ключ соответствующего сервиса в поле API-ключ, подтвердите условия и нажмите «Найти эпизоды». Длительность по умолчанию 60–90 с, цель 10, порог 60. При первом запуске/обновлении предложен видеорежим Gemini; далее выбранный режим запоминается. Локальный режим остаётся доступен без ключа и интернета, но его отбор ограничен эвристикой, а распознавание на старом CPU может занимать долгое время.
3. Проверьте предложенные эпизоды: балл не гарантирует интересность. Онлайн-режимы анализируют перекрывающиеся участки и сравнивают кандидатов для непересекающегося набора. При квоте или ошибке частичный результат помечается явно, повторный запуск продолжает кэш. Для десяти отдельных минутных клипов требуется хотя бы десять минут подходящего материала. Скорость зависит от подготовки медиа, сети, модели и квот; фиксированное время обработки не обещается.
4. Выберите строку и нажмите «Фрагмент». Воспроизведение останавливается на её конце. Без выбранного кандидата кнопка «Видео» воспроизводит исходник от позиции ползунка. Первый кадр загружается через FFmpeg; просмотр остаётся доступен во время анализа. Ползунок позволяет перемещаться по всему исходнику. Границы редактируются в таблице в формате `ЧЧ:ММ:СС.мс`. «＋ Вручную» создаёт отмеченный интервал от позиции ползунка. «Отметить все» отмечает показанные строки; «Показать ещё» раскрывает резерв после анализа.
5. Во вкладке «Расшифровка» исправьте текст и время реплик. Можно импортировать UTF-8 SRT. При следующем анализе сохранённый текст используется повторно. Очистка текста позволяет загрузить результат из кэша; для полного пересчёта удалите соответствующий кэш или смените его папку.
6. Во вкладке «Экспорт» выберите формат, разрешение, FPS, качество, высоту зоны видео и её отступ. Отметка 40% означает долю полной высоты холста. Субтитры: выключены, отдельный UTF-8 SRT или встроенные в MP4. Координата текста задаётся в процентах высоты и должна находиться внутри зоны видео. Очень длинные реплики лучше разделить вручную: текст уменьшается и ограничивается зоной видео.
7. «Экспортировать отмеченные». Каждый клип — один интервал; H.264/AAC, `yuv420p`, faststart. Чёрное поле не прозрачно. Экспорт идёт последовательно, проверяет геометрию/кодеки/длительность/стартовые метки и полностью декодирует результат. Существующие файлы не перезаписываются. При отмене готовые файлы остаются, временный текущий клип удаляется.
8. Сохраните проект. Он содержит метаданные, расшифровку, кандидатов и настройки, но не видео, модель или API-ключ. Повторный экспорт не запускает ИИ. После каждой распознанной минуты сохраняется контрольная точка в кэше: отмена не сбрасывает завершённые блоки, следующий поиск продолжает их. Индикатор показывает фактический прогресс Whisper; до первого ответа отображается ожидание с прошедшим временем. При перемещении исходника программа предложит привязать то же видео по SHA-256. Последние рабочие данные сохраняются в копии восстановления.

## Free API — первоначальная настройка

Для **Gemini Free** создайте ключ на https://aistudio.google.com/api-keys в проекте **без привязанного биллинга**. Видеорежим отправляет уменьшенную копию изображения со звуком на всю длительность записи; локальный Whisper не нужен. Модель получает выборку 2 кадра/с, поэтому очень быстрые действия и мелкие детали могут теряться. Копия имеет максимум 960×540 и 8 кадров/с; экспорт использует оригинал. Удаление загруженной копии запрашивается после обработки, при неподтверждённом удалении показывается предупреждение. Режим **Gemini Free · текст** сохраняет прежний путь: локальная расшифровка и отправка только текста, поэтому он не решает проблему медленного CPU-распознавания.

Для **Groq Free** создайте отдельный ключ на https://console.groq.com/keys на бесплатном аккаунте **без платёжного метода**. Передаётся звук, распознавание выполняет серверная модель `whisper-large-v3`, смысловой отбор — `openai/gpt-oss-120b`. Groq не оценивает визуальные события. Он формирует расшифровку для субтитров; видеорежим Gemini полной расшифровки сам не создаёт. Наличие Free и квот определяется аккаунтом/регионом.

**По API-ключу нельзя доказать отсутствие платёжного аккаунта. Клиентская программа не может гарантировать бесплатность ключа с уже включённым биллингом.** Если требуется технически исключить любые внешние расходы, используйте локальный режим.

Ключи сервисов разделены в Windows Credential Manager; если безопасное хранилище недоступно, остаются в памяти до закрытия. В проект/JSON-настройки ключи не записываются. При выборе сервиса показывается его собственный ключ. «Очистить» удаляет текущий ключ; «Проверить» обращается к метаданным без передачи исходного медиа и не подтверждает тариф. Согласие на передачу данных и отсутствие биллинга подтверждается один раз за сеанс для ключа/режима.

При 429 новые запросы останавливаются, готовые участки сохраняются; продолжите позже кнопкой «Найти эпизоды». Полностью завершённый анализ берётся из кэша без повторной передачи. Новые онлайн-режимы не повторяют неуспешные модельные запросы автоматически и не переключаются на платные тарифы/сервисы. Отмена сетевого запроса может занимать до 180 секунд плюс удаление видеокопии. Интерфейс остаётся доступным и показывает суммарное прошедшее время.

На бесплатном уровне Google может использовать отправленные материалы для улучшения продуктов, включая человеческую проверку. Для Groq проверьте Data Controls и условия обработки в консоли. Передавайте записи после осознанного согласия. Актуальные условия и квоты:

- https://ai.google.dev/gemini-api/docs/rate-limits
- https://ai.google.dev/gemini-api/terms

Документация проверена 12.11.2026. Для `gemini-2.5-flash` объявлено автоматическое перенаправление с 01.12.2026: поэтому по умолчанию выбран `gemini-2.5-flash-lite`, а старый Flash программно блокируется после указанной даты. Автоматического перехода на новую модель нет. Проверьте актуальную доступность и цену перед использованием API.

## Хранение и диагностика

«Настройки» позволяют выбрать FFmpeg, ffprobe, whisper-cli, модель, папки кэша и результата. Настройки, копия восстановления и ключ ОС отделены от папки проекта. Исходное видео читается, но не изменяется. Кэш содержит расшифровки и энергетику аудио, поэтому выбирайте подходящее место хранения. Для изолированной установки можно задать переменную `CLIPNADO_DATA_DIR`.

В Linux данные по умолчанию размещаются в `$XDG_DATA_HOME/ClipnadoStudioLite` или `~/.local/share/ClipnadoStudioLite`. В Windows — в `%LOCALAPPDATA%/ClipnadoStudioLite`.

GPU не обязателен. Для GTX 1660 нужна отдельная CUDA-сборка whisper.cpp с архитектурой `75`, совместимые драйвер/Toolkit и DLL. Включайте CUDA в настройках только после установки такой сборки. Комплектная сборка CPU; CUDA не проверена в этой среде.

## Запуск из исходников

Нужны Python 3.10–3.13 x64 и FFmpeg с `libx264`/`libass` в PATH или `tools/`.

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -e ".[dev]"
.venv\Scripts\python run.py
.venv\Scripts\python -m pytest -q
```

Linux: те же команды с `.venv/bin/python`; для тестов без дисплея — `QT_QPA_PLATFORM=offscreen`.

Нативная сборка Windows: `scripts/build_windows.ps1` (нужны Git, CMake и Visual Studio C++ Build Tools). Опция `-Cuda` требует CUDA Toolkit. Сценарий скачивает фиксированный исходный commit whisper.cpp и модель с проверкой SHA-256. `.github/workflows/deliver-windows.yml` выполняет нативную сборку, полный набор тестов, проверку переносимого пакета и загрузку файлов в Releases.

Текущий переносимый пакет собран и проверен на Windows Server 2022: официальный Windows Embedded Python 3.13.9, Windows wheels PySide6 6.8.3, FFmpeg 8.1.2 Gyan и нативная MSVC-сборка whisper.cpp/запускателя. `scripts/package_portable.py` собирает каталог из этих входов; `MANIFEST.json` содержит контрольные суммы. Исходный код приложения открыт, Qt загружается динамически, компоненты можно заменять.

Подробные результаты и оставшиеся проверки — в `QA_REPORT.md`. Лицензии и источники зависимостей — в `THIRD_PARTY.md` и `licenses/`.
