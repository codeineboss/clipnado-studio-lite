# Clipnado Studio Lite 0.1.9 — фактическая проверка

Проект восстановлен для нового аккаунта **codeineboss**. Ниже сохранены результаты прежнего прогона и обстоятельства старой блокировки; новый завершённый Windows-выпуск пока не подтверждён.

Исходники приложения и модели проверены на Windows Server 2022: **165 тестов прошли без пропусков**, 4220,76 с. Отдельная предварительная проверка автокадра/отмены: 51 тест, 17,12 с. Выполнены настоящие Whisper, Qwen, YuNet и Light-ASD. Полный прогон: https://github.com/Dan1elCarter67/clipnado-studio-lite/actions/runs/43869981174 . Ревизия приложения c913d75432832edd23a68de3c6493c302614a9e7; в 93542c01ef3aba22aa600c008b1b79b28f546f6b изменён только сценарий CI: лимит времени и раннее сохранение отчёта.

Новые проверки: реальные модели в отдельном процессе, кэш и удаление кадров, отмена, подавление кратких всплесков, движение лица, смена планов, настоящий MP4 с переключениями слева/справа, ненулевое начало клипа, звук, SRT/ASS, момент предпросмотра. MFCC и ONNX сравнивались с независимыми эталонами; подробности: qa/LOCAL_AUTOCROP_019.md.

**Проверка готового переносимого пакета не завершена.** Первый прогон достиг лимита CI 75 минут уже после успешных тестов. Повторная сборка 43882056467 запущена с лимитом 110 минут и защитой совпадения исходников. Затем GitHub вернул HTTP 403: `Your account was suspended`; её итог и публикация не подтверждены. Причина блокировки неизвестна. JUnit сохранён артефактом первого прогона; локально сохранена выдержка из фактического журнала, не синтетический JUnit.

Прилагаемый локальный ZIP — **обновление поверх рабочей переносимой версии 0.1.8**, не полная Windows-установка. Его содержимое/CRC/SHA проверены, зависимости совпадают с закреплёнными Windows wheels. Сам ZIP обновления не прошёл завершающий запуск через встроенный Windows Python. Подтверждать полную готовность переносимого пакета пока нельзя.

Автокадр не гарантирует верного говорящего при дубляже, речи за кадром и скрытых лицах. На одном реальном 20-секундном образце камера выбрала видимые лица и выполнила два переключения; это не размеченная оценка точности. Физические Xeon/GTX 1660/Windows 10 пользователя не проверены. Linux QEMU SandyBridge выполнил обе модели без AVX2/FMA/F16C/BMI2; это эмуляция, не проверка Windows на физическом CPU.
