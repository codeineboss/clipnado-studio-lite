# Перенос Clipnado в codeineboss

Исходный код подготовлен из проверенного локального Git bundle. Исходная сохранённая ревизия main — 93542c01ef3aba22aa600c008b1b79b28f546f6b. Все 32 прежних коммита и 4 ветки сохранены; исходный рабочий репозиторий не изменён.

Новый целевой адрес: https://github.com/codeineboss/clipnado-studio-lite . На момент подготовки репозиторий ещё не создан. Аккаунт codeineboss доступен, но подключение GitHub отклонило createRepository с сообщением Resource not accessible by integration. Для продолжения владелец должен создать пустой приватный репозиторий и предоставить подключению доступ.

В основной ветке обновлены активные ссылки на будущие выпуски. Исторические ссылки в QA-отчётах сохранены как свидетельства прежних проверок. Runtime-код, тесты, модели и сценарии сборки не изменены этим переносом.

Подтверждённый результат старого прогона: 165 тестов Windows, без пропусков. Его JUnit и служебные данные GitHub Actions недоступны из старого аккаунта. Финальная проверка готового переносимого пакета не завершена; новый выпуск необходимо проверить и опубликовать в новом репозитории. Старые issues, журналы Actions и страницы releases не входят в Git-историю и не переносятся автоматически.

Не помещайте Qwen GGUF в обычные Git-коммиты: это отдельный файл выпуска. Локальные копии GGUF и Whisper сохранены. После создания нового репозитория ветки можно отправить без force; приватность должна сохраниться.
